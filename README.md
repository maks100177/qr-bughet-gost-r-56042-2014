Генератор QR-кодов для бюджетных платежей (ГОСТ Р 56042-2014)

Профессиональное десктопное приложение для генерации платежных QR-кодов, совместимых с банковскими приложениями РФ (Сбербанк, ВТБ, Тинькофф и др.). Программа полностью соответствует стандарту ГОСТ Р 56042-2014 и предназначена для формирования платежек (госпошлины, штрафы, налоги, бюджетные услуги).

🚀 Основные возможности

    Полная совместимость: Генерирует QR-коды, которые мгновенно считываются мобильными приложениями банков.

    Умная история ввода:

        Программа запоминает введенные реквизиты.

        При следующем запуске автоматически подставляет последние использованные данные.

        История сохраняется локально на компьютере пользователя (в папке %APPDATA%), что позволяет запускать программу с общего сетевого диска (SMB) без конфликтов между сотрудниками.

    Валидация данных: Проверка заполнения обязательных полей (Получатель, Счёт, БИК) перед генерацией.

    Современный интерфейс: Темная тема, масштабируемость (Zoom) для удобной работы на мониторах любого разрешения.

    Удобство работы:

        Поддержка контекстного меню (Копировать/Вставить/Вырезать по ПКМ).

        Поддержка горячих клавиш (Ctrl+C, Ctrl+V, Ctrl+X).

    Экспорт: Возможность сохранить QR-код в формате .png.

🛠 Технический стек

Программа написана на языке Python.
Используемые библиотеки:

    customtkinter — современный графический интерфейс.

    qrcode — генерация матричного кода.

    pillow (PIL) — работа с изображениями.

📦 Установка и запуск (из исходного кода)

    Установите Python:

        Для поддержки Windows 7 используйте версию Python 3.8.10.

        Для Windows 10/11 можно использовать любую актуальную версию (3.10+).

        Важно: При установке поставьте галочку "Add Python to PATH".

    Клонируйте репозиторий:
    Откройте терминал (командную строку) и выполните:
    code Bash

    git clone https://github.com/maks100177/qr-bughet-gost-r-56042-2014.git
    cd qr-bughet-gost-r-56042-2014

    Установите зависимости:
    code Bash

    pip install customtkinter qrcode[pil] packaging pillow

    Запустите программу:
    code Bash

    python main_final_v2.py

⚙️ Компиляция в EXE (Создание файла для пользователей)

Чтобы создать один файл .exe, который работает без установки Python, используется библиотека PyInstaller.

    Установите упаковщик:
    code Bash

    pip install pyinstaller

    Выполните команду сборки:
    code Bash

    pyinstaller --noconfirm --onefile --windowed --collect-all customtkinter main_final_v2.py

        --onefile — собрать всё в один файл.

        --windowed — скрыть черное окно консоли при запуске.

        --collect-all customtkinter — Обязательно! Копирует темы и стили интерфейса внутрь exe.

    Готовый файл будет лежать в папке dist/.

🖥 Развертывание в локальной сети (SMB)

Программа оптимизирована для работы в корпоративной сети.

    Скомпилируйте файл .exe.

    Поместите файл в общую сетевую папку (например, \\Server\Common\QR_Gen).

    (Рекомендуется) Установите атрибут "Только чтение" для файла .exe (Свойства -> Только чтение), чтобы пользователи случайно не удалили его и не блокировали файл для обновления.

    Создайте ярлыки на рабочих столах пользователей.

Как работает история в сети?
Даже если 100 человек запустят один и тот же файл с сервера, их данные не перемешаются. Программа создает файл истории ИМЯ_ПК.json в личной папке пользователя:
C:\Users\<Имя_Пользователя>\AppData\Roaming\QRBudgetHistory\
📖 Инструкция пользователя

    Запуск: Откройте программу.

    Заполнение: Введите реквизиты.

        Поля, отмеченные *, обязательны (Получатель, Счет, БИК, Банк, Корр.счет).

        Остальные поля (КБК, ОКТМО, Назначение) заполняются при необходимости.

    Генерация: Нажмите зеленую кнопку "Сгенерировать".

        Справа появится QR-код.

        Программа автоматически запомнит введенные данные.

    Проверка: Откройте приложение банка на телефоне, выберите "Оплата по QR" и наведите камеру на экран.

    Сохранение (Опционально): Если нужно отправить QR-код по почте, нажмите синюю кнопку "Сохранить PNG".

    Повторный вход: При следующем открытии программы последние данные подставятся автоматически. Если нужно выбрать более старые данные — нажмите на стрелочку в поле ввода.

❗ Решение проблем

1. Программа не запускается на Windows 7

    Причина: Вы скомпилировали программу, используя новую версию Python (3.9 или выше).

    Решение: Установите Python 3.8.10, создайте виртуальное окружение и скомпилируйте проект через него.

2. Ошибка "API-MS-WIN-CORE..."

    Решение: Требуется установить обновления Windows 7 (KB2533623) или пакет Visual C++ Redistributable 2015-2019.

3. Не работает вставка текста (Ctrl+V)

    В программе реализована принудительная поддержка горячих клавиш. Убедитесь, что раскладка клавиатуры не мешает, или воспользуйтесь контекстным меню (Правая кнопка мыши -> Вставить).
