# Генератор QR-кодов для бюджетных платежей (ГОСТ Р 56042-2014)

![alt text](https://img.shields.io/badge/Python-3.8%2B-blue)
![alt text](https://img.shields.io/badge/GUI-CustomTkinter-green)
![alt text](https://img.shields.io/badge/License-Free-orange)

> **Профессиональное десктопное приложение** для генерации платежных QR-кодов. Полностью соответствует стандарту **ГОСТ Р 56042-2014**. Коды мгновенно считываются приложениями **Сбербанк**, **ВТБ**, **Тинькофф** и др.

---

## 🚀 Основные возможности

### 💎 **Функционал**
*   ✅ **Полная совместимость:** 100% гарантия считывания банковскими приложениями работает без ИНТЕРНЕТА.
*   🛡️ **Валидация:** Программа не даст создать некорректный QR без обязательных полей (БИК, Счёт, Получатель).
*   💾 **Экспорт:** Сохранение результата в **.PNG** для отправки по почте/распечатке в документе и тд.

### 🧠 **Умная память**
*   **Автозаполнение:** Программа запоминает всё, что вы вводили. При перезапуске данные подставляются сами.
*   **Сетевая безопасность:** История хранится **ЛОКАЛЬНО** (`%APPDATA%`), поэтому программу можно запускать с общей сетевой папки — данные сотрудников не перемешаются.

### 🎨 **Интерфейс**
*   **Modern UI:** Приятная темная тема (Dark Mode).
*   **Zoom:** Масштабирование интерфейса (80% – 150%) для любых мониторов.
*   **Hotkeys:** Работают привычные `Ctrl+C` / `Ctrl+V` и контекстное меню.

## 📦 3. Установка и запуск (Dev Mode)

*Этот раздел нужен только программисту. Обычные пользователи запускают EXE.*

### 🔹 Шаг 1. Подготовка Python
*   Для **Windows 7** ➔ Установите строго **Python 3.8.10**.
*   Для **Windows 10/11** ➔ Любая версия **Python 3.10+**.
> ⚠️ **Важно:** При установке обязательно поставьте галочку `Add Python to PATH`.

### 🔹 Шаг 2. Клонирование репозитория
Откройте терминал (CMD) и введите:
```bash
git clone https://github.com/maks100177/qr-bughet-gost-r-56042-2014.git
cd qr-bughet-gost-r-56042-2014
```

### 🔹 Шаг 3. Установка библиотек
```bash
pip install customtkinter qrcode[pil] packaging pillow
```

### 🔹 Шаг 4. Запуск скрипта
```bash
python QRCODGEN.py
```

## ⚙️ 4. Компиляция в EXE (Обязательно для пользователей)

Чтобы ваши сотрудники могли запускать программу **без установки Python**, вы должны "собрать" её в один `.exe` файл.

### 🔹 Шаг 1. Установите сборщик
```bash
pip install pyinstaller
```

### 🔹 Шаг 2. Соберите проект
Введите эту команду целиком (она подключит стили интерфейса):
```bash
pyinstaller --noconfirm --onefile --windowed --collect-all customtkinter QRCODGEN.py
```

### 🔹 Шаг 3. Заберите файл
Готовый файл `QRCODGEN.exe` появится в папке `dist/`.

> **Совет:** Для совместимости с **Windows 7** собирайте проект строго в окружении **Python 3.8**.

## 🖥 5. Развертывание в сети (SMB)

Идеально для офиса. **Пользователям НЕ НУЖНО устанавливать Python.** Они просто запускают готовый файл.

1.  Возьмите созданный ранее файл `QRCODGEN.exe` (из папки `dist`).
2.  Положите его в общую папку: `\\Server\Soft\QR_Gen`.
3.  💡 **Совет:** Поставьте файлу атрибут **"Только чтение"** (свойства файла), чтобы его случайно не удалили.
4.  Раздайте ярлыки пользователям.

**Где хранится история?**
Данные не перемешиваются! У каждого пользователя создается своя локальная папка на его ПК:
`C:\Users\<USER>\AppData\Roaming\QRBudgetHistory\<ИМЯ_ПК>.json`

## 📖 6. Как пользоваться

1.  **Запуск:** Откройте приложение `QRCODGEN.exe`.
2.  **Заполнение:**
    *   Поля со звездочкой `*` — **Обязательные** (Получатель, Счета, БИК).
    *   Остальные — по ситуации (КБК, ОКТМО).
3.  **Генерация:**
    *   Нажмите зеленую кнопку **[Сгенерировать]**.
    *   **ПРОКРУТИТЕ В САМЫЙ НИЗ, на экране под полями ввода появится QR-код.**
4.  **Оплата:**
    *   Откройте приложение банка (Сбер, Тинькофф...).
    *   Выберите "Оплата по QR" ➔ Наведите камеру.
5.  **Сохранение:**
    *   Нажмите синюю кнопку **[Сохранить PNG]**, чтобы скачать картинку на компьютер.

## ❓ 7. Решение проблем (FAQ)

| Проблема | Причина | Решение |
| :--- | :--- | :--- |
| ❌ **Ошибка на Windows 7** | EXE собран на новом Python (3.9+) | Пересоберите проект, используя **Python 3.8.10** |
| 🧩 **Нет DLL (api-ms-win...)** | Старая Windows 7 | Установите обновление **KB2533623** или Visual C++ 2015-2019 |
| ⌨️ **Не работает Ctrl+V** | Особенности раскладки | Используйте **ПКМ ➔ Вставить** или проверьте раскладку (EN/RU) |
| 🗑️ **Как стереть историю?** | Нужно сбросить данные | Нажмите красную кнопку **[Очистить память]** в меню |
